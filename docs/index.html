Coverage

Six things a browser will never tell you

Run from one command, or pick exactly what you need from the menu.

01

Page basics

Title, description, canonical, H1, Open Graph, Twitter cards — length and presence checks, not just existence.

02

AI crawler access

Whether GPTBot, ClaudeBot, and PerplexityBot can read the page, and whether content only exists after JS hydration.

03

Whole-site crawling

Reads the sitemap, follows sitemap indexes, and surfaces duplicate titles and descriptions across every page.

04

Broken links

Checks every link with HEAD, falling back to GET. Timeouts are reported separately from real breakage.

05

Core Web Vitals

LCP, CLS, TBT, FCP, and TTFB on both mobile and desktop — mobile throttled to match Lighthouse.

06

Structured data

Validates JSON-LD — including nodes inside @graph — against what Google requires for rich results.

Real audits

Not hypothetical checks

Two problems sitebot found on live sites — both invisible in a browser.

200 to you, 503 to Google

A pharmacy site's product page loaded fine in a browser but returned 503 to every crawler — Googlebot, GPTBot, ClaudeBot — because a prerender service was silently failing behind the scenes.

x-prerender-status: FAIL-RENDER-ERROR vary: User-Agent status: 503

Duplicate descriptions across a crawl

A single-page check can't catch this — only a crawl can. The same meta description turned up on four different changelog pages of a live production site.

"The best way to deploy your Next.js site." on 4 pages

Get started

Install

Nothing to keep updated, nothing to sign into.

Run it once, no install
❯ npx sitebot-cli https://example.com
Or install globally
❯ npm install -g sitebot-cli
❯ sitebot https://example.com

Requires Node.js 22+. Chromium only downloads if you ask for --vitals, and sitebot asks first.

Run it on your own site.

Takes under ten seconds. Nothing to configure.

❯ npx sitebot-cli https://your-site.com
